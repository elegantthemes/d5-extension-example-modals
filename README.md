# D5 Extension Example: Modals

Collection of example custom modals for Divi 5 demonstrating different modal implementation patterns and functionality.

## Examples Included

### 1. Module Visibility Manager
- **Purpose**: Filter which modules appear in the module library
- **Demonstrates**: Field persistence, GroupContainer, Toggle fields, Redux store
- **Location**: `/module-visibility-manager/`

### Future Examples
- Additional modal examples will be added to demonstrate various Divi 5 modal patterns

## Installation
1. Clone into `/wp-content/plugins/` directory
2. Navigate to example directory (e.g., `module-visibility-manager/`)
3. Run `yarn install` and `yarn build`
4. Activate the specific example plugin in WordPress admin

## Requirements
- WordPress with Divi theme
- Divi 5 Visual Builder enabled
- Node 20+ for building examples
